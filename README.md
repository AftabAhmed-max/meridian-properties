# Meridian Properties — Where Vision Meets Value

> Premium real estate advisory across the UAE and Gulf region.

🌐 **Live Site:** [meridian-properties-eta.vercel.app](https://meridian-properties-eta.vercel.app/)

---

## About

Meridian Properties is a fictional premium real estate agency website built as a portfolio showcase project for Stackwork. It demonstrates a fully functional property listing platform tailored for the Gulf market, featuring property search, filtered listings, dynamic detail pages, and lead generation forms.

---

## Pages

- **Home** — Hero with property search bar, featured listings, services, stats, and testimonials
- **Properties** — Full listings page with filter by type, location, and budget
- **Property Detail** — Individual pages with image gallery, description, amenities, map, and inquiry form
- **About** — Agency story, team, and key market stats
- **Contact** — Inquiry form, office details, and Google Maps embed

---

## Key Features

- 12+ fictional property listings across apartments, villas, and townhouses
- Dynamic routing for individual property detail pages
- Filterable listings by property type, location, and budget
- Static JSON data — no paid database required
- Fully responsive across mobile, tablet, and desktop

---

## Tech Stack

| Technology | Purpose |
|---|---|

| Unsplash | Photography |

## Running Locally

```bash
git clone https://github.com/AftabAhmed-max/meridian-properties.git
cd meridian-properties
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
